# Randflow

A citizen view of South African public money.

The budget pages use the 21 October 2026 Medium Term Budget Policy Statement. The tender register and the company-link chart read a live slice of National Treasury’s eTenders portal. An award is not proof the work was done well, and a closed tender often has no winner published.

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
